Full description

The position is on securing and strengthening Kubernetes platforms as well as implementing modern security standards and automated security controls. You work closely with development and architecture teams and support the construction and operation of a robust and secure platform.

Your tasks

  • Responsibility for security and hardening of on-premises Kubernetes platforms
  • Implementation and enforcement of Kubernetes Security Best Practices
  • Configuration and operation of network policies, pod security standards, RBAC and secrets management
  • Implementation of security assessments and vulnerability analysis
  • Integration of security scans and security controls in CI/CD pipelines
  • Monitoring and analysis of security incidents
  • Automation of security controls using Infrastructure as Code (IaC)
  • Support in securing and further developing the container and Linux infrastructure
  • Close cooperation with development and architecture teams
  • Participation in the definition and implementation of a robust and hardened Kubernetes platform

Your profile

  • Several years of practical experience in operating and securing Kubernetes environments
  • In-depth knowledge of Kubernetes Hardening, Container Security and Linux Security
  • Experience with CI/CD, GitOps and Infrastructure as Code (IaC)
  • Experience with cloud and/or on-premises Kubernetes platforms
  • Knowledge of implementing security best practices for Kubernetes
  • Experience with security-relevant technologies such as Keycloak, OpenBao or Cilium is an advantage
  • Experience with Security Scanning and Vulnerability Management
  • Analytical and solution-oriented procedure
  • High security awareness and a strong sense of responsibility
  • Enjoy working with development, security and architecture teams
  • Very good knowledge of German and English
